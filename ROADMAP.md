# Roadmap

What's planned, roughly in order. Each step can ship on its own. Open issues have the details; ideas outside this list are welcome as issues.

## Next

- Performance: measure styling with `os_signpost`, restyle the visible area first, plain-text mode for very large files.
- Remote images off by default in export and print, with a setting to allow them.
- Copy as Rich Text.
- Draw tables as a grid in the editor without changing the file.
- Notarized downloads on GitHub Releases and a Homebrew cask.

## Later

- Quick Look extension.
- Welcome note, "What's New" and the default-app question on first launch.
- App Intents (Shortcuts).
- Front matter shown as a properties box.
- Folder mode: file tree, folder search, `[[wiki links]]` and backlinks.
- More interface languages.

## Not planned

A separate preview pane, sidebars or themes. QuickMD keeps one view on purpose.
