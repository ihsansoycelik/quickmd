Report an issue

Open an issue on GitHub. Please include your macOS version, the QuickMD version (QuickMD › About QuickMD) and, if you can, a small .md file that shows the problem.

Common questions

Is my note changed by the styling? No. Files stay plain Markdown on disk.

How do I make QuickMD the default for .md files? QuickMD › Default App for Markdown. macOS asks you to confirm.

Pictures in my note don't show. QuickMD draws local images only after you allow access to the note's folder, when it asks.
